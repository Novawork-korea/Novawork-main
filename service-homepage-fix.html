WHAT YOU GET

제공 결과물

합의한 범위의 수정 파일, 변경 내역, 동작 확인 결과를 제공합니다. 사용 중인 플랫폼이나 외부 서비스의 제약은 사전에 확인해 작업 범위에 반영합니다.

MADE FOR YOU

문제 확인부터 수정 검수까지,
변경 내용을 명확하게.

01

문제 재현과 수정 범위

오류가 발생하는 화면과 재현 조건, 사용 중인 제작 도구를 확인합니다. 코드 접근 여부와 기존 구조를 검토해 수정 가능한 항목과 작업 범위를 정합니다.

02

화면·기능·콘텐츠 개선

문구와 이미지, 화면 배치, 링크와 버튼 동작, 모바일 레이아웃을 개선합니다. 추가 기능은 기존 구조와의 연결 가능성을 확인한 뒤 적용 범위를 정합니다.

03

변경 내역과 동작 검수

수정한 화면과 주요 동작을 확인하고, 변경한 파일과 내용을 구분해 전달합니다. 운영에 필요한 안내와 추가로 확인해야 할 사항을 기록합니다.

기능과 제공 범위는 현재 운영 환경과 요구사항을 확인한 뒤 정합니다.
