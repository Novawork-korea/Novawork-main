HOW WE WORK

진행 방식

지금의 업무를 이해하는 것부터, 완성된 도구를 직접 사용하는 순간까지.

01

현재의 일을 함께 살핍니다.

누가 어떤 순서로 일하는지, 어디에서 시간이 걸리는지 확인합니다. 지금 쓰는 파일·화면·도구가 가장 좋은 출발점입니다.

02

만들 범위를 분명히 정합니다.

필요한 화면과 기능, 데이터 연결 방식, 검수 기준을 정리합니다. 견적과 일정, 수정·지원 범위도 개발 전에 확인합니다.

03

화면을 보며 방향을 맞춥니다.

주요 화면과 업무 흐름을 먼저 확인합니다. 시안에서 보이는 기능과 실제로 연결된 기능을 구분하고, 피드백을 반영합니다.

04

실제 환경에서 확인합니다.

합의한 기능을 구현하고 로그인, 입력, 저장, 조회 같은 사용 흐름을 점검합니다. 외부 연동은 사용할 계정과 실행 환경에서 확인합니다.

05

직접 쓸 수 있게 인계합니다.

합의한 소스·설정 파일과 사용 방법을 전달합니다. 운영에 필요한 계정, 별도 이용료, 완료 후 지원 범위와 기간을 함께 안내합니다.

BEFORE WE START

이야기할 수 있습니다.
