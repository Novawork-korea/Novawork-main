01 / 납품 완료 · 기존 PC 프로그램

네이버 쇼핑
순위 확인 자동화

매번 검색하고 옮기던 일을,
결과를 확인하는 흐름으로.

불편했던 일
검색어마다 상품을 찾고, 확인한 결과를 시트에 옮기는 반복 작업.
만든 흐름
검색어·상품코드 등록 → PC Chrome 조회 → Google Sheets 기록.
확인된 범위
기존 PC 확장·시트 연동 프로그램의 고객 테스트와 납품을 완료했습니다.

이 환경에서 실행합니다.

PC와 Chrome이 켜져 있어야 합니다. 로그인 상태와 네이버 접속 제한에 따라 조회가 중단될 수 있습니다.

02 / 자체 테스트 환경

로그인 이후의
업무까지, 한곳에서.

고객에게는 배정된 도구를.
관리자에게는 사용자 관리 화면을.

만든 흐름
로그인 → 배정된 프로그램 → 업무 처리. 관리자는 사용자와 프로그램 연결을 관리합니다.
확인된 범위
자체 테스트 환경에서 로그인 유지·로그아웃, 업무 생성·수정·삭제와 관리자 연결 기능을 확인했습니다.

추가 확인이 필요한 부분

포털에 연결한 Chrome 확장의 실제 PC 네이버 조회는 추가 확인이 필요합니다. 자체 테스트 환경을 고객 납품 실적으로 소개하지 않습니다.
