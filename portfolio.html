SELECTED WORK

작업 사례

직접 만든 도구와 검토 중인 화면을 소개합니다. 납품된 프로그램, 테스트 환경, 디자인 시안을 구분했습니다.

01납품 완료 · 기존 PC 프로그램

매번 검색하던 일을,
결과 확인으로.

검색어와 상품코드를 등록하면 PC의 Chrome 확장이 네이버 쇼핑 결과를 읽고, 상위 3위 포함 여부를 Google Sheets에 기록합니다.

확인된 범위
기존 PC 확장·시트 연동 프로그램은 고객 테스트와 납품을 완료했습니다.
실행 조건
PC와 Chrome이 켜져 있어야 합니다. 로그인 상태와 네이버 접속 제한에 따라 조회가 중단될 수 있습니다.
반복 확인을 줄이는 방식 ↗

02테스트 환경 운영

로그인하고,
내 업무를 이어서.

계정에 배정된 프로그램으로 들어가 업무를 만들고 수정합니다. 네이버 순위 프로그램도 같은 작업공간에 연결했습니다.

확인된 범위
업무 생성·수정·삭제, 로그인 유지와 로그아웃을 테스트 환경에서 확인했습니다.
추가 확인 사항
포털과 연결한 Chrome 확장의 실제 PC 네이버 조회는 추가 확인이 필요합니다.

03디자인 시안

흩어진 도면과 발주를,
한 흐름으로.

메일 접수, 업체별 첨부파일, 도면 정보 검토, 납기별 진행 현황을 연결하는 화면을 구성했습니다.

현재 상태
예시 데이터로 접수부터 검토까지의 흐름을 살펴보는 웹 시안입니다.
개발 단계에서 확인
실제 메일 연동, 도면 정보 추출, 사용자 간 데이터 공유는 별도 구현·검증 대상입니다.
업무 흐름을 연결하는 방식 ↗

04디자인 시안

여러 링크의 유입을,
한 화면에서.

채널별 링크를 통해 들어오는 흐름과 결과 조회 화면을 제안한 시안입니다. 실제 유입 기록을 보여주는 운영 화면은 아닙니다.

현재 상태
유입 경로와 집계 화면을 설명하기 위한 예시 데이터 기반 시안입니다.
개발 단계에서 확인
실제 이동·기록, 누락 처리, 집계 결과는 정식 연동 후 확인해야 합니다.
